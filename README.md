# Personal Portfolio Website

A responsive personal portfolio website built as part of the **CodeAlpha Frontend Development Internship**.

## 🔗 Live Site
Not hosted yet — open `index.html` locally, or host free via [GitHub Pages](https://pages.github.com/).

## 📌 About
A single-page portfolio showcasing background, skills, projects, and a working contact form — built from scratch with vanilla HTML, CSS, and JavaScript.

## ✨ Features
- Fully responsive layout (mobile, tablet, desktop)
- **Scroll-reveal animations** — sections fade and rise into view as you scroll
- About, Skills, Projects, and Contact sections
- Working contact form (via Formspree — submissions delivered directly to inbox)
- Smooth scroll navigation, hover effects
- Accessible: visible keyboard focus states, respects reduced-motion preferences

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox, custom properties, transitions)
- JavaScript (IntersectionObserver for scroll animations, Fetch API for the contact form)
